# Solana Shores: Vice Syndicate

An original 3D open-world crime action game set in the sun-drenched coastal city of Solana Shores. Explore freely on foot or behind the wheel, commandeer exotic rides, take on syndicate contracts, fight rival crews, and outrun the aggressive SSPD police tactical cruisers.

## Controls
- **WASD / Arrow Keys**: Move character / Steer & accelerate vehicle
- **Mouse**: Rotate camera (Click canvas to enable Pointer Lock)
- **E**: Enter / Exit vehicle
- **F**: Interact / Commandeer vehicle / Action
- **Space**: Jump (on foot) / Handbrake (driving)
- **Left Mouse Click**: Melee strike / Fire weapon
- **R**: Reload weapon
- **1 / 2**: Switch weapon (Fists / 9mm Pistol)
- **Escape / P**: Pause menu
